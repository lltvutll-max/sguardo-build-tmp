# Локализация Sguardo iOS

Языки интерфейса: **ru** (исходный — ключи каталога русские), **en, de, fr, es, pt, it, pl** — как на сайте.
Для остальных языков системы приложение показывает **en** (`CFBundleDevelopmentRegion = en` в `Resources/Info.plist`).

Файлы:
- `App/Localizable.xcstrings` — строки интерфейса (String Catalog, `sourceLanguage: ru`).
- `App/InfoPlist.xcstrings` — тексты разрешений (`NSCameraUsageDescription` и др.). Новый ключ Info.plist с текстом для человека — сюда же.
- `tools/check-xcstrings.py` — проверка (JSON, все 8 языков, plural, подстановки, каждая русская строка из кода есть в каталоге).
- `tools/i18n-merge.py` — добавить строки в каталог из простого JSON (без Xcode).
- Пункт «Язык» в профиле открывает системные настройки приложения (там iOS даёт выбрать язык).

## Правило: как добавить новую строку (обязательно для каждого нового экрана)

1. **В коде** — только локализуемые литералы:
   - прямо в SwiftUI: `Text("Удалить аккаунт")`, `Button("Отмена")`, `Label("Поддержка", systemImage: …)`, `.navigationTitle("…")`,
     `.alert("…")`, `.confirmationDialog("…")`, `TextField("…", …)`, `.accessibilityLabel("…")` — переводятся сами;
   - всё, что уходит в `String` (свои компоненты `SheetBox(title:)`, `Chip(text:)`, `store.show(…)`, `return` из функции, тернарник, массивы):
     `String(localized: "…")`. Тернарник в Text: `Text(f ? String(localized: "Да") : String(localized: "Нет"))`.
   - **не склеивать** фразы из кусков (`"Выбрано: " + n`): одна фраза = один литерал с интерполяцией `String(localized: "Выбрано: \(n) чатов")`.
   - интерполировать только `String`, `Int`, `Double` (не Optional, не Substring/CGFloat/enum — привести явно).
   - даты и время — `Date.FormatStyle` / `RelativeDateTimeFormatter` текущей локали (или `Fmt.*` из Components.swift), никаких русских месяцев и `Locale(identifier: "ru_RU")`.
   - НЕ переводить: данные сервера и клиентов (сообщения, имена, названия папок/меток — показываем `name` как есть), бренды
     (Sguardo, Telegram, WhatsApp, Instagram, Threads, TikTok), тексты ошибок, пришедшие с сервера. Если русский литерал должен
     остаться как есть — в конце строки комментарий `// i18n: no`.
2. **Ключ каталога** = текст литерала, где `\(x)` заменено: `String` → `%@`, `Int` → `%lld`, `Double` → `%lf`; символ `%` → `%%`
   (только в строках с подстановками). Пример: `"Выбрано: \(n) чатов"` (n: Int) → ключ `Выбрано: %lld чатов`.
3. **Переводы** — во все 8 языков, сразу. Файл `new.json`:
   ```json
   [{"key": "Удалить аккаунт", "en": "Delete account", "de": "Konto löschen", "fr": "Supprimer le compte",
     "es": "Eliminar cuenta", "pt": "Excluir conta", "it": "Elimina account", "pl": "Usuń konto"},
    {"key": "Выбрано: %lld чатов",
     "ru": {"one": "Выбран %lld чат", "few": "Выбрано %lld чата", "many": "Выбрано %lld чатов", "other": "Выбрано %lld чата"},
     "en": {"one": "%lld chat selected", "other": "%lld chats selected"},
     "de": {"one": "…", "other": "…"}, "fr": {"one": "…", "other": "…"}, "es": {"one": "…", "other": "…"},
     "pt": {"one": "…", "other": "…"}, "it": {"one": "…", "other": "…"},
     "pl": {"one": "…", "few": "…", "many": "…", "other": "…"}}]
   ```
   `python3 tools/i18n-merge.py new.json` — слить в `App/Localizable.xcstrings` (для Info.plist: `python3 tools/i18n-merge.py new.json App/InfoPlist.xcstrings`).
   - plural (число + склоняемое слово): ru/pl — `one/few/many/other`, остальные — `one/other`; в plural-ключе ровно одна подстановка
     (несколько — формат `subs`, см. docstring `tools/i18n-merge.py`).
   - несколько `%@` с другим порядком в переводе — `%1$@`, `%2$@`.
4. **Проверка**: `python3 tools/check-xcstrings.py` → `ошибок: 0` и нет строк «НЕ ЛОКАЛИЗОВАНО» по новым файлам;
   `/root/bin/swift-syntax-check App` → 0 problems.

## Термины (как в веб-версии, `socialmedia-admin/src/i18n/dict/*.json`)

| ru | en | de | fr | es | pt | it | pl |
|---|---|---|---|---|---|---|---|

| метка | tag | Label | étiquette | etiqueta | etiqueta | etichetta | tag |
| напоминание | reminder | Erinnerung | rappel | recordatorio | lembrete | promemoria | przypomnienie |
| кабинет | account | Konto | espace | cuenta | conta | account | panel |
| клиент | client | Kunde | client | cliente | cliente | cliente | klient |
| сводка | digest | Übersicht | récapitulatif | resumen | resumo | riepilogo | podsumowanie |
| партнёры | partners | Partner | partenaires | socios | parceiros | partner | partnerzy |
| обещание | promise | Versprechen | promesse | promesa | promessa | promessa | obietnica |
| рассылки | Outreach | Versand | Envois | Envíos | Envios | Invii | Wysyłki |

## Снимки
`64-chats-en` и `65-profile-de` в `.github/workflows/build.yml` запускаются с `-AppleLanguages (en)` / `(de)`.
Свой экран на другом языке: `shoot NN-имя -fixture -screen … -AppleLanguages "(fr)" -AppleLocale fr_FR`.
